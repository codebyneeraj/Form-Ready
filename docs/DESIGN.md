# Design notes (from "FormReady App Screens.html"; per-screen markup in docs/design/*.html)

Font Montserrat 500/600/700/800 (bundle locally, no CDN). Mobile frame 390x844, white bg, 20px padding.
Colours: text #1A1A1A, muted #5A5A5A, border #E6E6E6, brand orange #C93A00 (text/accents) / #D13F00 (primary button),
orange tint #FFF1EA, green #138808 (borders/toggle) / #0E6B06 (text) / tint #EAF5E8 / row tint #F4F9F3,
red text #8C1A14 / tint #FDECEA, amber text #8A5A00 / tint #FFF6E5, neutral tint #F4F4F4.
Radii: cards 16, buttons 14 (h 54 primary, h 48 secondary outline #D9D9D9), pills 999. Back button 44x44 r12.
Flow: 1 Pick exam -> 2 Add files -> 3 Checks (fixes needed | ready) -> 5 Privacy -> 6 Download. 7 = laptop layout (two columns, upload left, checks right; wraps under ~900px).
Copy rules: "predicts", never "guarantees"; "Nothing leaves your phone"; show MEASURED numbers, not targets.
Sample exams in design: Central Recruitment, Railway Recruitment, Bank Clerk, State Services (all "(sample)", "Rules verified: [date]").
